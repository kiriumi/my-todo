# MY-TODO

ブラウザだけで動く、個人用のTODO/タスク管理アプリです。インストール不要・サーバー不要で、[my-todo.html](my-todo.html) 1ファイルだけで完結します。

## 特徴

- **TODOリスト（案件状況ボード）**: セクション（取引先・プロジェクト単位など）ごとに作業を一覧表示。分類・内容・期間・作業・状況・期限・備考・優先度を管理できます。
- **今週TODO**: 期限が近い作業や「今週やる」に指定した作業だけを優先度別に表示する専用ビュー。
- **セルを直接クリックして編集**（モーダルを開かずその場で編集可能）
- **ドラッグ&ドロップ**で行やセクションの並び替え、別セクションへの移動
- **複数選択**（⠿をShift/Ctrl+クリック）してまとめて移動
- **列ソート**、セクション・優先度グループの折り畳み
- **Markdown書き出し**（案件状況・今週TODOをそれぞれ `.md` として出力）
- **バックアップ/復元**（全データをJSONファイルに書き出し、別のブラウザ・PCへ移行可能）

## 使い方

[my-todo.html](my-todo.html) をブラウザで開くだけで使えます。

```bash
start my-todo.html
```

または、ファイルをブラウザのタブにドラッグ＆ドロップしてください。

## データの保存について

- 入力したデータはブラウザの `localStorage` に自動保存されます（サーバーへの送信は一切ありません）。
- ブラウザのキャッシュ・データを消去すると保存内容も失われるため、別ブラウザ・別PCで使う場合や念のためのバックアップには、画面上部の「💾 バックアップ」からJSONファイルを書き出し、「📂 復元」で読み込んでください。
- 初回起動時はサンプルデータが表示されます。各行の🗑やセクションの🗑から削除して、実データの入力を始められます。

## 動作環境

モダンブラウザ（Chrome、Edgeなど）であれば追加設定なしで動作します。ビルドツールや依存パッケージは不要です。
